UI 与交互批注

1
高对比进度核

56dp 触控区、52dp 半透明中性灰容器、3.5dp 青色圆头环；沿用应用黑白与青色强调色。

2
两行可扫读详情

主行只放阶段和百分比，副行放大小与速度；高度始终 56dp，超长内容省略。

3
锚点不跳动，也不盖信息

进度核固定在屏幕边缘；只有标题空白安全带允许状态自动展开，拖到标题或内容区域后保持紧凑球，点按才临时展开。

4
持续运动只留给圆环

未知进度采用可变弧长旋转；常规进度不呼吸、不反复弹跳，减少工具页面干扰。

5
拖拽有拿起与落边

越过阈值放大至 1.04 并提升阴影；吸边结束做一次横向挤压回弹。

6
结果反馈有轻重

成功补满绿环并轻弹，停留 1.5 秒；失败转红并短促回弹，信息保留 3 秒。

解析结果决定界面

作品类型由链接解析结果自动识别，用户不需要、也不能手动切换作品类型。页面始终只显示一组“保存内容”Tabs。

识别为视频作品
视频封面音频
默认选中“视频”；不显示 Live 视频勾选按钮。底部为“复制链接 + 保存视频”，切换 Tab 后保存按钮对应变为“保存封面”或“保存音频”。
识别为普通图集
图片封面音频
默认选中“图片”；不显示 Live 视频勾选按钮。底部为“复制链接 + 保存图片”，切换 Tab 后保存按钮对应变为“保存封面”或“保存音频”。
识别为 Live 图作品
图片封面音频□ Live 视频
默认选中“图片”。只有“解析结果 = Live 图”并且“当前 Tab = 图片”两个条件同时满足，底部才显示“复制链接 + Live 视频勾选 + 保存图片”；切换到封面或音频后隐藏勾选按钮。
“Live 视频”是附加保存选项，不是作品类型 Tab。勾选后保存原图和每张图片对应的动态视频。
