异常日志复制｜交互说明

这是独立确认原型，不会修改正式 Android 页面。异常日志入口只放在“我的”中，点击手机里的按钮查看状态变化。

推荐操作路径

  1. 解析失败时，解析页只显示失败提示和“重新解析”，不暴露诊断入口。
  2. 进入“我的”，可选择登录 WebView，也可以保持未登录继续使用匿名解析。
  3. 在“我的 → 异常日志”中查看事件列表，再点某一条看详情。
  4. 点击“复制当前日志”，复制脱敏文本并显示轻量 Toast。

日志字段

作品链接 原始链接会截断查询参数；渠道 标记匿名解析、Cookie 兜底或重试；报错信息 保留用户可读错误；返回摘要 记录 HTTP 状态、页面状态标记、资源数量；解析异常 记录异常类型和阶段。

脱敏边界

日志中不出现 Cookie、Token、完整签名参数、完整响应正文或媒体直链。复制内容只用于定位“哪条链接、哪个阶段、哪个渠道、哪种返回状态”出了问题。
